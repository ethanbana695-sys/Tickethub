TICKETHUB STARTER WEBSITE

WHAT IS INCLUDED
- Responsive English football ticket storefront
- Search and filter sample match listings by league
- Basket with quantity controls and totals
- Demo admin panel to add/remove fixtures and set prices/stock
- Browser localStorage persistence

IMPORTANT LIMITATIONS
- The fixtures are SAMPLE DEMO DATA, not live or verified fixtures.
- The listed prices and ticket quantities are placeholders.
- No real payments, customer accounts, order database, email delivery, seat maps,
  inventory locking, or secure admin authentication are connected.
- Do not accept payment or advertise tickets as available until you have verified
  ticket inventory and the legal right/authorisation to resell each ticket.
- The admin panel is not password-protected and changes are stored only in the
  visitor's browser. It is for preview/testing, not production administration.

PREVIEW
Open index.html in a browser, or upload the contents of this folder to a static
host such as Cloudflare Pages or Vercel.
